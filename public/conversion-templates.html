Conversion Templates
A Conversion Template is a cut-down copy of the target schema: for each Configurator module in scope, the real target tables it maps to. The client builds a staging database in that exact shape and hands it over, so the same standard import scripts run for every conversion. Phase 1 defines the table list per module; column detail is read live from the target when the specification is generated.
