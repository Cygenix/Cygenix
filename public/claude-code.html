Claude Code — connection test

Can Anthropic's workspace reach your database?

The Claude Code console runs code in an isolated workspace hosted by Anthropic, which connects to your database directly. Before the console is switched on, this test checks that the workspace can open a connection to your database server and that the server answers, and reports the IP address the workspace connects from.

It sends only the server name, port and database type. No user name, password or data leaves this page, and nothing is run against the database. It runs on your own Anthropic API key, costs a few cents, and is capped at US$6.00 (about £5). Only an Organisation Owner or Platform Administrator can run it.

No Anthropic API key is saved in this browser. Add it in Settings → General, then come back.

Server to test

The allow-list test is the one that matters: it is how the console will run, reaching only your server. The open-networking test tells you, when the first one fails, whether the allow-list is the cause or the network itself.
