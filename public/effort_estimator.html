Data Conversion Standard Estimation Model
Use case estimates
The seven standard use cases. A new estimate starts at FULL SCOPE — every module ticked — so you untick what the client is not buying; an untouched use case costs nothing. TC is the technical complexity factor: 1 is standard, up to 99 for fully custom.
Data model estimates
Counts per module: source systems, attributes and relationships, each weighted into data function points.
Variables
Project-level multipliers applied to every use case. A scale variable at its minimum is neutral; a flag applies its weight when on. A weight may be negative to CUT effort — a staging-only migration is less work than source → staging → prod. Combined factor: ×1.0
Modules
The product areas in this migration, each with a complexity weight — ×1 is standard, Proforma might be ×0.5 and Trust ×1.5. A ticked module contributes its weight to every use case it appears on. Removing a module clears its ticks, counts and weight.

How it estimates
Use-case FP = (base + per-module × the ticked modules' weights) × variables × TC, and zero with nothing ticked — each module's complexity weight (×1 standard) scales what it adds, so a simple module opens a use case without costing like a hard one. Variable weights may be negative, so a variable can cut effort as well as add it; no single variable can take the estimate below a twentieth of its unweighted value — effort can be reduced, never erased. Data FP adds source systems ×3, attributes ×0.05, 1:1 relationships ×0.5 and 1:N ×1 per module. Total FP × days-per-FP (default 1.37) gives working days; divided by 19.5 gives calendar months; the delivery date walks forward from the start date over working days plus holidays, skipping weekends. The verdict compares working days needed against working days available before the due date, and the baseline note compares them against the standard quote (days, weeks or months — yours to set). "Calibrate rate to baseline" tunes days-per-FP so a FULLY ticked estimate — every module on every use case — lands exactly on the baseline, so partial scopes price proportionally inside the standard quote. Estimated cost is simply total hours × the hourly rate. Every weight on this page is visible and editable — an estimate nobody can inspect is an estimate nobody trusts.
