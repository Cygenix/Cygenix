Connection Profiles
A profile is a governed pairing of one source and one target. Artifacts bind to a profile — never to whatever connection happens to be loaded — so every run can prove which databases it touched. Once the first profile exists, writes require an active profile, an UNKNOWN environment blocks writes, and PRD writes need a typed confirmation.

Environment sentinel
a marker row inside each database that names its profile, environment and role — the strong identity check. Install needs CREATE TABLE once per database (an operator action); the assertion needs SELECT only.
The one real hole: restoring a production backup over a lower environment copies the production sentinel with it, and the sentinel then vouches for the wrong environment. Re-seed immediately after ANY restore — including Cygenix's own Restore database and Data import functions.
